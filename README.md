# OpenCart Selenium Automation Testing

## 📌 Project Overview

This project is a **web application automation testing project** for the OpenCart demo application using Selenium WebDriver.

The purpose of this project is to automate selected functional test cases and verify that important OpenCart features work as expected.

## 🎯 Project Objective

* Automate functional test cases for the OpenCart application.
* Validate different application modules using Selenium WebDriver.
* Perform positive and negative test scenarios.
* Verify expected results using TestNG assertions.
* Execute and maintain automated test cases using Maven.

## 🛠️ Technologies & Tools

* **Programming Language:** Java
* **Automation Tool:** Selenium WebDriver
* **Testing Framework:** TestNG
* **Build Tool:** Maven
* **IDE:** Eclipse
* **Version Control:** Git & GitHub
* **Application Under Test:** OpenCart Demo

## 🧪 Automation Coverage

The automation project covers selected test cases from different OpenCart modules, including:

* Account Registration
* Login
* Forgot Password
* Search
* Wishlist
* Shopping Cart
* Product-related functionality
* Other selected functional scenarios

The project contains multiple automated test cases created to validate positive and negative application behavior.

## ▶️ How to Run the Project

### Prerequisites

Make sure the following are installed:

* Java JDK
* Eclipse IDE
* Maven
* Chrome Browser

### Steps

1. Clone the repository.

2. Open the project in Eclipse as a Maven project.

3. Allow Maven to download the required dependencies.

4. Verify the browser and test configuration.

5. Run the required TestNG test class or execute the test suite using `testng.xml`.

## 📊 Test Execution

The automated test cases are executed using **TestNG**.

TestNG assertions are used to compare the actual application behavior with the expected result and determine whether the test passes or fails.
